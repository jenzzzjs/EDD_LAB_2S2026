Actúa como un diseñador y desarrollador web experto en Frontend. Tu tarea es diseñar la interfaz de usuario para una plataforma web de música con un estilo moderno, limpio e intuitivo.

Restricciones Técnicas
Lenguajes: Únicamente HTML5 y CSS3 (sin frameworks de JS como React/Vue, ni frameworks de CSS como Tailwind o Bootstrap).

Paleta de Colores: Basada en tonos azul y negro (puedes incluir variantes como azul noche, azul eléctrico, gris oscuro y acentos para contrastes).

Estilo Visual: Moderno, neomórfico o dark mode elegante, orientado a experiencias de transmisión/música contemporáneas.

Vistas a Diseñar
Landing Page (Página de Inicio)

Header con navegación principal y botones de acción (Login/Registro).

Sección Hero con un eslogan atractivo y llamadas a la acción (CTA).

Sección de características clave (descubrir música, listas personalizadas, etc.).

Sección de planes/suscripciones.

Footer con enlaces informativos y redes sociales.

Registro e Inicio de Sesión (Register & Login)

Formularios limpios, estilizados con CSS, centrados y responsivos.

Campos estructurados con validación visual básica (estilos hover, focus y active).

Panel de Usuario / Dashboard (Rol: Usuario Registrado)

Sidebar o menú de navegación con acceso a: Inicio, Explorar, Biblioteca, Listas de Reproducción y Perfil.

Reproductor de música fijo (Bottom Player) con controles (Play, Pause, Progress Bar, Volumen).

Grilla de tarjetas (cards) para álbumes, canciones populares y artistas recomendados.

Vista de perfil del usuario para editar información básica.

Panel de Administración / Dashboard (Rol: Administrador)

Menú de gestión: Métricas principales, Gestión de Usuarios, Catálogo de Música y Reportes.

Tabla estilizada para listar, editar y eliminar usuarios o canciones.

Tarjetas con métricas rápidas (ej. usuarios activos, canciones subidas).
